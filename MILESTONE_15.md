# MILESTONE_15 - Separar fichas y puntos del mes

## Objective
El jugador ve dos números distintos: las fichas para jugar y los puntos del mes que valen para el premio.

## Key Concepts
Hoy un solo número (el saldo) sirve para jugar y para el ranking. Eso permite trampas: pasarse fichas entre cuentas. En este paso la interfaz enseña fichas (para entrar a una partida) y puntos del mes (para el premio). El developer aprende a no mezclar “puedo jugar” con “voy primero”. Los siguientes milestones usarán solo los puntos del mes en la clasificación.

## Checklist

- [x] Mostrar las fichas donde el jugador entra a jugar (navbar / lobby)
- [x] Mostrar los puntos del mes junto a la idea de premio o ranking
- [x] Dejar claro con texto corto qué número es cada uno
- [x] No usar las fichas como si fueran el puesto del mes
- [x] Quien no tiene puntos del mes aún ve 0, no un saldo inventado

## Acceptance Criteria

- En pantalla se distinguen fichas y puntos del mes.
- El número de fichas no se presenta como puesto para el premio.
